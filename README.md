# DMART Sales Analysis Dashboard
# Project Description

The DMART Sales Analysis Dashboard is an interactive Business Intelligence solution developed using Power BI to analyze sales performance, customer behavior, product categories, and operational efficiency. The dashboard provides a comprehensive view of key business metrics through dynamic visualizations, enabling data-driven decision-making and performance monitoring.

The dashboard integrates multiple analytical perspectives, including revenue trends, order performance, customer demographics, marketing effectiveness, discount analysis, and geographical sales distribution. Interactive filters allow users to explore data by product, city, shipping mode, and other business dimensions.

# Key Features
Revenue and Sales Performance Monitoring
Total Revenue, Order Count, Average Order Value, and Order Cancellation KPIs
Year-wise Revenue Trend Analysis
Marketing and Advertisement Performance Analysis
Customer Demographic Analysis by Age Group
Product Category Revenue and Discount Contribution Analysis
Order Status Performance Tracking
Geographic Sales Distribution Map
Interactive Filtering and Drill-Down Capabilities\

# Business Insights Generated
Identify high-performing marketing channels driving customer engagement.
Monitor yearly sales growth and revenue trends.
Analyze customer purchasing behavior across different age groups.
Evaluate product category performance and discount effectiveness.
Track order fulfillment, cancellations, returns, and delivery performance.
Understand regional sales distribution and market penetration.
